고윳값·고유벡터 구하기: det(A − λI) = 0

A = (2 1 / 1 2)로 해볼게요.

① A − λI = (2−λ  1 / 1  2−λ)
② det = (2−λ)² − 1 = λ² − 4λ + 3 = 0 특성방정식
③ (λ − 3)(λ − 1) = 0 → λ = 3, 1
④ (A − λI)v = 0 풀기
  λ = 3: (−1 1 / 1 −1)v = 0 → −x + y = 0 → v = (1, 1)
  λ = 1: (1 1 / 1 1)v = 0 → x + y = 0 → v = (1, −1)
⑤ 확인: A(1, 1) = (3, 3) = 3(1, 1) ✓

2×2 지름길: λ² − (trace)λ + det = 0. 고유벡터는 크기가 아니라 방향이라서 (2, 2)나 (−1, −1)도 같은 고유벡터예요. R은 길이 1로 맞춰 (0.707, 0.707)처럼 보여주고, 부호는 반대로 나올 수 있어요.

AAᵀ와 AᵀA는 어떤 A든 항상 정방 + 대칭

원소로: AAᵀ의 (i, j) = i행 · j행 = j행 · i행 = (j, i). 예: (1, 2) = 20×14 + 18×12 + 16×10 = 656 = (2, 1).
식으로: (AAᵀ)ᵀ = (Aᵀ)ᵀAᵀ = AAᵀ.

AAᵀAᵀA
크기행 수 × 행 수열 수 × 열 수
(i, j)i행 · j행: 관측치끼리 유사도i열 · j열: 변수끼리 관계
공통대칭, 고윳값 ≥ 0 (양의 준정치), 0이 아닌 고윳값은 서로 같음

SVD와 PCA

A = UΣVᵀ. SVD는 넣어준 행렬을 그대로 분해하므로 σ²은 항상 제곱합이에요. 평균을 뺀 Xc를 넣으면 그 제곱합이 (n − 1) × 분산이 되고, 그게 PCA예요. prcomp()는 XᵀX를 만들면서 생기는 반올림 오차를 피하려고 eigen 대신 SVD를 써요.

SVDPCA 의미prcomp
V의 열주성분 방향$rotation
σ² / (n − 1)주성분 분산$sdev^2
UΣ = XcV주성분 점수$x

평균을 빼지 않는 SVD는 0이 "없음"인 데이터에서 일부러 써요: 문서×단어 빈도(LSA), 픽셀 밝기(이미지 압축), 사용자×상품 평점(추천). 이때 σ²은 분산이 아니라 그 방향의 에너지이고, 평균을 빼지 않아야 희소성(대부분 0)도 유지돼요.

3×3 행렬곱

AB=AB

예: c11 = (1, 2, 0) · (1, 3, 0) = 1 + 6 + 0 = 7. 3×3 행렬은 3차원 공간의 점을 옮겨요: A·(1, 1, 1) = (3, 4, 3).

3×3 행렬식은 첫 행 전개, 부호 + − +:
det A = 1(1·1 − 3·0) − 2(0·1 − 3·2) + 0 = 1 + 12 = 13

3×3×3 텐서 (축 A, B, Z)

축이 세 개라서 어느 축끼리 짝지을지 정해야 해요(텐서 축약). 규칙: ① 짝지을 축의 길이가 같고 ② 그 축 방향으로 곱해 더하면 축이 사라지고 ③ 남은 축이 이어 붙어 결과 모양이 돼요.

결과 차원 수 = 3 + 3 − 2 × (축약한 축 수). 행렬곱은 2 + 2 − 2 = 2라서 계속 행렬이었어요.
