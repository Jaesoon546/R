매개변수 쿼리와 저장 프로시저

값을 문자열로 붙이면 x' OR '1'='1 같은 입력이 SQL 문법이 되어 전체 데이터가 새어 나가요(SQL 인젝션). ? 자리에 값을 따로 넣으면 순수한 데이터로만 들어가요. Flask의 cursor.execute("... %s", (name,))와 같은 원리예요.

@ 변수는 같은 연결 안에서만 유지돼요. SET → CALL → SELECT를 같은 con으로, 연결을 닫기 전에 실행하세요. 다시 실행하면 같은 학생이 또 들어가요. SELECT 결과를 돌려주는 프로시저는 dbSendQuery + dbFetch + dbClearResult로 받아요.
